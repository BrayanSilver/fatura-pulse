# FaturaPulse

Dashboard de faturamento para TV, com dados fictícios gravados no navegador.

Abas: Indicadores, Notas, Clientes, Canais e Faturamento. Filtros de mês, regional, estado, representante e canal. Nenhuma informação é enviada a um servidor.

## Rodar localmente

```bash
npx serve .
```

Abra `index.html`.
